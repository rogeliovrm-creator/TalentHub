Incorpora registros sin volver a capturar perfiles existentes o previamente vistos.

IMPORTA · COMPARA · REGISTRA

Una sola persona, una sola ficha.

Sube Excel o CSV, relaciona las columnas, revisa coincidencias y agrega únicamente los nuevos. Los perfiles vistos permanecen en el historial aunque elimines su ficha.

1. Selecciona una base de datos

Archivos .xlsx, .xlsm, .csv o .tsv, hasta 20 MB. La lectura se realiza en este dispositivo: no se suben tus archivos a ningún servidor. Para archivos .xls antiguos, usa «Guardar como .xlsx» en Excel.

Haz clic o arrastra aquí tu archivo ExcelTambién puedes cargar listas de personas previamente contactadas.

Todavía no has seleccionado ningún archivo.

2. Relaciona las columnas

Detecté las columnas comunes automáticamente. Si tu base usa otros nombres, elige la columna correspondiente para cada dato. Nombre es obligatorio para altas en el roster.

¿Qué quieres hacer con esta base?

3. Revisa el resultado antes de importar

Las coincidencias seguras se omiten. Los casos dudosos no se importan automáticamente. Puedes corregir la base y volver a cargarla.
