TALENTHUB PERSONAL V4.1 — PTP Y CUMPLEAÑOS VISIBLES

ACTUALIZAR GITHUB + VERCEL:
1. En el TalentHub actual, antes de modificar nada, descarga un respaldo JSON desde Configuración.
2. Entra a GitHub y abre el repositorio conectado a Vercel.
3. Abre index.html, pulsa el botón de edición y reemplaza su contenido con el de este index.html, o elimina el antiguo y carga el nuevo con el mismo nombre.
4. Haz Commit changes en la rama de producción. Espera a que Vercel marque el despliegue como Ready.
5. Entra a la misma dirección de TalentHub, actualiza la pestaña con Ctrl+F5 (Windows) o abre una pestaña nueva. Debe aparecer «GESTIÓN DE TALENTO · V4.1» en Inicio.
6. Las secciones «PTP próximos a vencer» y «Próximos cumpleaños» deben ser visibles aunque no haya fechas.

FUNCIONAMIENTO:
- PTP: selector 30, 60, 90 (predeterminado) o 365 días. Incluye vencidos.
- Cumpleaños: selector 7, 30, 60, 90 y todo el año (predeterminado).
- Se cuentan solo empleados ACTIVOS. Las fichas sin fecha se señalan bajo cada panel.
- Cuando no hay fechas, aparecen explicaciones, no desaparecen las secciones.
- El resto de los empleados y fichas sigue en el almacenamiento local del mismo navegador y URL.
- Publicar el archivo no carga datos personales a GitHub. No subas respaldos JSON al repositorio.

Si ves una versión anterior, comprueba que hayas subido el index.html al repositorio correcto y que la compilación de Vercel haya terminado. Si la versión es V4.1 y los registros están vacíos, verifica fechas en las fichas.
